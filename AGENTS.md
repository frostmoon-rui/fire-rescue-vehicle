# Repository maintenance

- Keep all public text, comments, filenames and user-facing messages in English.
- Publish only technical project files. Do not add personal records, competition paperwork, Wi-Fi credentials, participant information, unreviewed media or vendor application bundles.
- Preserve upstream attribution and licenses. Do not claim autonomous navigation, firefighting capability or hardware validation without corresponding implementation and test evidence.
- Never execute or flash firmware during offline validation. Run `python -m unittest discover -s tests -q` and inspect the staged file list before committing and pushing verified changes to this repository's own origin.
- Preserve original local archives. Never force-push or rewrite remote history without explicit approval.
